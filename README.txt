GONI COMMUNICATION - EDITABLE WEBSITE

1. Extract this ZIP into one folder.
2. Keep index.html, admin.html, data.js, logo.png, songgram.jpg, imran-ali.png in the SAME folder.
3. Double-click index.html to open the website.
4. Click "Admin" at the bottom, or open admin.html.
5. Default admin password: 1234
6. From Admin Panel you can edit:
   - ISP name, owner name, phone, intro, description
   - Add/Edit/Delete technicians
   - Add/Edit/Delete services
   - Add/Edit/Delete apps/links
   - Download/restore a JSON backup

IMPORTANT:
This version uses browser localStorage, so it is a working local CMS but NOT a secure public online admin system.
For a public website where you can log in from any phone/laptop and changes update for everyone, the next step is connecting a free backend/database such as Supabase or Firebase. Do not use this local password system for a public production site.
